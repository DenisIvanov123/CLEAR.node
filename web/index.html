Как работает запуск через браузер

Интеграция Custom Protocol smremote://

1. Десктопный агент в трее

Приложение SM Remote v1.2.3+ должно быть запущено на вашем компьютере (оно сворачивается в системный трей возле часов).

2. Автозапуск вместе с Windows

Вы можете поместить ярлык SM Remote.exe --tray в автозагрузку (нажмите Win+R → shell:startup), чтобы агент всегда тихо работал в фоне.

3. Клик в веб-портале

При нажатии кнопки «ЗАПУСТИТЬ» браузер передает ссылку в SM Remote через протокол smremote://. Агент мгновенно стартует нужное приложение (iikoOffice, RDP, AnyDesk) без необходимости держать открытым главное окно программы.
